Anvil is a small desktop browser built in Rust, Go (`engines/go`, the pure-Go **Anvil Forge Engine** in `anvil-engine`, and the six pure-Go companion libraries `anvil-json`, `anvil-compress`, `anvil-hpack`, `anvil-pqc`, `anvil-gpu`, and `anvil-video`), C++20 (native Direct2D + DirectWrite + Win32/DWM desktop UI shell in `ui/` and SIMD/VM helpers in `engines/`), JavaScript/TypeScript (`frontend/` and self-hosted **Cinder** JS VM & JIT in `engines/cinder`), and CSS (**Prism** CSS engine in `engines/prism/stylesheets/` and `frontend/styles/`), powered by the **Anvil Forge Engine** (`anvil-engine`) and integrating Brave Browser's open-source `adblock-rust` crate (`../adblock-rust`, MPL-2.0) for network and cosmetic ad/tracker blocking. It runs on Linux and Windows.

It's a proof of concept, so expect rough edges. Current version: 0.24.5.1 (`v.24.5.1`).

See [CHANGELOG.md](./CHANGELOG.md) for what changed in each release.

## Try it

Windows 64-bit builds (`AnvilBrowser-Setup-v.24.5.1-win64.exe` and a portable `anvil.exe`) are on the [releases page](https://github.com/buntatoes/anvil-browser/releases), or build it from source below.

## Build it

You need Rust 1.99.1 or newer and Go 1.22 or newer. On Linux you also need the X11 and OpenSSL development files (`sudo apt install libx11-dev libssl-dev` on Debian or Ubuntu). A C++20 compiler builds the native Direct2D/DirectWrite desktop UI engine (`ui/`) on Windows and the C++20 CSS/JS engine helpers (`engines/prism/cpp` and `engines/cinder/cpp`), while `go` compiles the in-tree Go engine (`engines/go`), the pure-Go **Forge** engine (`anvil-engine`), and the pure-Go companion libraries (`anvil-json`, `anvil-compress`, `anvil-hpack`, `anvil-pqc`, `anvil-gpu`, and `anvil-video`).

Clone this repo, [anvil-engine](https://github.com/buntatoes/anvil-engine), [adblock-rust](https://github.com/brave/adblock-rust), and the nine companion libraries below side by side in one folder, then run this from `anvil-browser`:

```sh
cargo test -- --test-threads=1
cargo run --release -p anvil-browser --bin anvil
```

- **Networking, TLS, and Go engines**: Speaks HTTP/1.1 and HTTP/2 (over ALPN `h2` on Windows Schannel and Linux OpenSSL) with origin-keyed connection pooling, cookies, HSTS, CSP, and Subresource Integrity (`sha256-` and `sha3-256-`), backed by the 100% pure-Go **Anvil Forge Engine** (`anvil-engine` 0.24.5.1 / `v.24.5.1`), the six 100% pure-Go companion libraries `anvil-hpack` 0.2.0 (`v.02`, RFC 7541 HPACK header compression), `anvil-compress` 0.4.0 (`v.04`, RFC 1951/1950/1952 DEFLATE, zlib, and gzip), `anvil-json` 0.4.0 (`v.04`, RFC 8259 JSON + RFC 6901 JSON Pointer), `anvil-pqc` 0.3.0 (`v.03`, NIST FIPS 203 ML-KEM-768, RFC 7748 X25519, `X25519MLKEM768` hybrid KEM, and FIPS 202 SHA-3/SHAKE), `anvil-gpu` 0.12.0 (`v.12`, 2D compositor passes, 16x16 tile device, and embedded HLSL/GLSL shaders), and `anvil-video` 0.11.0 (`v.11`, RFC 6716 Opus, RFC 6386 VP8, VP9, AV1 OBU, and AVID/ADCT/MP4/fMP4/WebM codecs), plus the in-tree `engines/go` module (`AnvilGoEngine`, HAR 1.2 network trace analysis, diagnostic bundle archiving, and `VerifyGoModulesSelfTest`). On Linux, OpenSSL offers the `X25519MLKEM768` post-quantum hybrid group first and shows the negotiated group on `anvil://security`. `anvil-net` also includes an in-house TLS 1.3 implementation built on `anvil-pqc` and `anvil-cipher`; page loads still connect through OpenSSL or Schannel after the TLS 1.3 self-test passes.
- **Process isolation, Brave Shields, and privacy**: Runs each tab in its own `--renderer` process (with optional Linux `bwrap`/`unshare`/`prlimit` confinement, Windows job limits and low-integrity labels, and a checked painted-frame draw mode on `anvil://security`). Links Brave Browser's unmodified `adblock-rust` crate (`adblock::Engine`, MPL-2.0) for ABP/uBlock Origin network filter matching, `@@` exceptions, `$important`, `$redirect` script/frame surrogates, `$removeparam` tracking query parameter stripping, cosmetic element hiding (`##` and `#@#`), and per-site Shields Up/Down controls on `anvil://shields` (`anvil://security`). Supports HTTPS-only mode, top-level site cookie partitioning, and per-site script and cookie permissions.
- **Native C++20 desktop UI, responsive 1080p/1440p/4K scaling, tabs, and tools**: Renders the browser shell chrome through a native C++20 Direct2D + DirectWrite + Win32/DWM UI engine (`ui/anvil_core_abi.h`, `ui/anvil_ui_d2d.cpp`, `ui/anvil_ui_window.cpp`) with ClearType proportional typography (`Segoe UI`, `Segoe UI Semibold`, `Cascadia Mono`), monitor-aware default window sizing and high-DPI zoom for 1080p (`1920x1080`), 1440p (`2560x1440`), and 4K (`3840x2160`) displays, an integrated 38px top tab strip with `4x4` SSAA anti-aliased Anvil emblem (`anvil-image` 0.8.0 mipmap downsampling), adaptive tab widths, draggable titlebar region, and Windows 11 Minimize/Maximize/Close caption buttons, a pill-shaped Omnibox with domain-highlighted URL (`split_url_for_domain_highlight`), inline Security pill, inline Shields pill, and floating suggestion popover, a floating bottom-left link-hover/loading status pill, zero-copy and dirty-row (`D3D11_BOX`) Direct3D 11 SwapChain presentation (`present.rs`), and responsive 2-column left sidebar navigation + multi-column card layouts across `anvil://home`, `anvil://settings`, `anvil://security`, `anvil://downloads`, `anvil://history`, and `anvil://inspector`. Supports pinned tabs, tab reordering (`Ctrl+Shift+PageUp`/`PageDown`), closed-tab restore (`Ctrl+Shift+T`), duplicate/close-other-tabs, four themes (`Dark`, `Midnight`, `Light`, `Nordic`), mouse-drag page text selection, full caret and word-level text editing, a 5-tab `F12` DevTools dock (`Elements`, `Styles` with live inline CSS override editing, `Network` waterfall log, `Console` REPL, and `Storage` inspector), `view-source:` (`Ctrl+U`), `Ctrl+S` page saving, automatic file downloads (`anvil://downloads`), find in page (`Ctrl+F`), and page zoom (`75%`–`150%`).
- **Media, maps, and search**: Decodes PNG, JPEG, GIF, WebP (`VP8L` and `VP8 `), BMP, ICO, and TrueType/OpenType fonts (`glyf`, `CFF `, `kern`, `GPOS`). Plays `AVID`/`ADCT`, RFC 6386 `VP8`, clean-room `VP9` (uncompressed header + 8x8 DCT/IDCT intra/inter frames + superframe index), and `AV1` (`AOMedia OBU` sequence/frame headers + 8x8 DCT/IDCT intra/inter + CDEF filter) MP4/WebM clips and RFC 6716 `Opus` (SILK/CELT) / `PCM` / `ADPCM` / `FLAC` / `MDCT` audio with `anvil-video` 0.11.0 (`v.11`) and `AudioOutputBridge` master audio clock A/V drift tracking and streaming PCM16 ringbuffer. While `anvil-video` 0.11.0 implements specification-guided RFC 6386 VP8, VP9, AV1 OBU, and RFC 6716 Opus codecs, it does not implement every third-party entropy/transform mode, and H.264 containers still wrap `ADCT` payloads. Includes a built-in tile map (`anvil://maps`) and clean result formatting for Google, DuckDuckGo, and Bing search pages.

## How it's laid out

This repo houses the browser shell and host-bridge crates (`crates/`), the native C++20 Direct2D/DirectWrite desktop UI engine (`ui/`), the TypeScript/TSX built-in pages (`frontend/`), the in-tree Go engine (`engines/go`), and the in-tree **Prism** CSS engine (`engines/prism`) and **Cinder** JS VM & JIT (`engines/cinder`) that link directly into the Rust core (`anvil-style` and `anvil-script`). The pure-Go **Anvil Forge Engine** lives in [anvil-engine](https://github.com/buntatoes/anvil-engine) (Go), Shields adblocking links Brave Browser's unmodified [adblock-rust](https://github.com/brave/adblock-rust) crate (`MPL-2.0`), and the browser builds with all nine standalone companion libraries (six in 100% pure Go and three in Rust):

- [anvil-cipher](https://github.com/buntatoes/anvil-cipher), [anvil-compress](https://github.com/buntatoes/anvil-compress) (Go), [anvil-hpack](https://github.com/buntatoes/anvil-hpack) (Go), [anvil-image](https://github.com/buntatoes/anvil-image), [anvil-json](https://github.com/buntatoes/anvil-json) (Go), [anvil-pqc](https://github.com/buntatoes/anvil-pqc) (Go), [anvil-ttf](https://github.com/buntatoes/anvil-ttf), [anvil-gpu](https://github.com/buntatoes/anvil-gpu) (Go), [anvil-video](https://github.com/buntatoes/anvil-video) (Go)
