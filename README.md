Anvil is a desktop browser built in Rust, Go, C++20, and TypeScript/JavaScript, powered by the in-tree **Anvil Forge** (`anvil-forge`) engine and integrating Brave Browser's open-source [`adblock-rust`](https://github.com/brave/adblock-rust) crate (`MPL-2.0`) for network and cosmetic ad/tracker blocking. It runs on Windows and Linux.

It's a proof of concept, so expect rough edges. Current version: 0.25.0 (`v.25`).

See [CHANGELOG.md](./CHANGELOG.md) for what changed in each release.

## Try it

Windows 64-bit builds (`AnvilBrowser-Setup-v.25-win64.exe` and a portable `anvil.exe`) are on the [releases page](https://github.com/buntatoes/anvil-browser/releases), or build it from source below.

## Build it

You need Rust 1.99.1 or newer, Go 1.22 or newer, and a C++20 compiler. On Linux you also need the X11 and OpenSSL development files (`sudo apt install libx11-dev libssl-dev` on Debian or Ubuntu). All browser crates, UI components, and in-tree engines are self-contained inside this repository and compiled automatically by `cargo`.

Clone this repo and [adblock-rust](https://github.com/brave/adblock-rust) side by side in the same parent folder, then run from `anvil-browser`:

```sh
cargo test -- --test-threads=1
cargo run --release -p anvil-browser --bin anvil
```

## What it does

- **HTML, CSS, and layout**: Parses HTML with WHATWG HTML5 error recovery (active formatting element reconstruction across misnested inline tags, table foster parenting, implicit heading/paragraph/list/table auto-closure, and foreign `<svg>`/`<math>` self-closing tags), inline `<svg>` icons and shapes, tables (`colspan`, `rowspan`, and intrinsic column sizing), `<details>`/`<summary>` accordions, `<dialog>` modal/non-modal elements, Shadow DOM (`attachShadow` with open/closed mode and `<slot>` composed-tree projection), Custom Elements (`customElements.define`, `upgrade`, `whenDefined`, and lifecycle callbacks), and form controls (`<input>`, `<textarea>`, `<select>`, checkboxes, radios, range sliders, `<progress>`, and `<meter>`, with `application/x-www-form-urlencoded` and RFC 7578 `multipart/form-data` boundary serialization and `formaction`/`formmethod`/`formenctype` submitter overrides). Applies the CSS cascade with dirty-subtree incremental style invalidation (`compute_styles_incremental`) and incremental layout subtree caching (`LayoutCache` / `layout_document_incremental`): Selectors Level 4 (`:scope`, `:host`, `:host()`, `:host-context()`, `::slotted()`, `::part()`), `@font-face`, `font-family` (`Sans`, `Serif`, `Mono`), `text-transform`, `letter-spacing`, `word-spacing`, `text-decoration: underline | line-through`, `::before` and `::after` generated content pseudo-elements, interactive/validation states (`:hover`, `:active`, `:focus`, `:focus-visible`, `:focus-within`, `:target`, `:valid`, `:invalid`, `:in-range`, `:out-of-range`), CSS Nesting (`&`), `@media`, `@supports`, `@layer` cascade layers with `!important` layer inversion and `revert-layer`, `@scope (<root>) to (<limit>)`, `@property` custom property registration, CSS-wide keywords (`initial`, `inherit`, `unset`, `revert`, `revert-layer`, `all`), `@container` size queries, `@starting-style`, CSS Color 4/5 (`color(display-p3 | xyz-d50 | xyz-d65)`, `color-mix()`, `light-dark()`, linear/radial/conic/repeating gradients), `backdrop-filter: blur(...)` and `filter`, per-side border colors, `outline`/`outline-offset`, `object-fit`, scrollable overflow containers (`overflow: auto | scroll` with mouse-wheel routing and 6px overlay scrollbars), `position: sticky` scroll-anchored offset clamping (`top`, `bottom`, `left`, `right`) across parent containing blocks, scrollable overflow containers, and viewport scrollports (`find_node_rect_in_view` and `hit_test_scrolled`), W3C stacking context order, CSS Values 4 math (`calc()`, `min()`, `max()`, `clamp()`, `round()`, `mod()`, `rem()`, trig/exponential), `text-overflow: ellipsis`, `overflow-wrap: break-word` / `word-break: break-all`, CSS Logical Properties, standalone `translate`/`scale`/`rotate`, custom properties (`var(--*)`) with inheritance across Shadow DOM boundaries, `box-sizing`, `aspect-ratio`, Flexbox and CSS Grid, transitions, and keyframe animations. Draws through batched scene passes (`GpuSceneBatch`) with gamma-correct linear-space glyph blending, multi-family bold/italic glyph synthesis, 4-bin (`0.25 px`) subpixel phase positioning, pairwise kerning, and bounded glyph and image caches.
- **JavaScript and WebAssembly**: Runs page scripts and WebAssembly 1.0 modules under a step and memory budget with per-`<script>` and statement-level fault isolation (`window.onerror`, `ErrorEvent`, `PromiseRejectionEvent`, `unhandledrejection`). Supports ES2022–ES2024 classes/`#private` fields/destructuring/regex/`async`-`await`, Generators (`function*`/`yield`/`yield*`), Async Generators (`async function*` / `for await...of` / `[Symbol.asyncIterator]`), `BigInt`, ES module `import`/`export`/`import.meta`/`import()` lowering, `Proxy` and `Reflect`, `WeakMap`/`WeakSet`/`WeakRef`/`FinalizationRegistry`, `DataView`/`ArrayBuffer`/`TypedArray`s, `Symbol.for`/`Symbol.keyFor`, `Error(..., { cause })`, `AggregateError`, `Intl`, W3C `MutationObserver`, W3C `CustomElementRegistry`, Shadow DOM `<slot>` APIs, W3C 3-phase DOM event propagation (`Capture -> Target -> Bubble` with `once`/`capture`/`passive`/`signal`/`stopImmediatePropagation`/`composedPath`), live layout/scroll DOM geometry (`getBoundingClientRect()`, `getComputedStyle(el, pseudoElt)`, `offsetWidth`/`offsetHeight`, `clientWidth`/`clientHeight`, `scrollWidth`/`scrollHeight`, `scrollTop`/`scrollLeft`, `scrollTo`/`scrollBy`), HTML5 `<dialog>` (`show()`/`showModal()`/`close()`), HTML5 Form Constraint Validation (`validity`/`checkValidity()`/`reportValidity()`/`setCustomValidity()`), `FormData(formElement?, submitter?)` with automatic RFC 7578 `multipart/form-data` request body serialization in `fetch()`, `Request`, and `XMLHttpRequest.prototype.send()`, `File`/`FileList`/`FileReader`/`DataTransfer`/`navigator.clipboard`, live scroll/resize `IntersectionObserver` & `ResizeObserver` re-evaluation, `Element`/`ChildNode`/`ParentNode` mutation methods, `TreeWalker`/`NodeIterator`/`Range`/`Selection`, `fetch`/`Headers`/`Request`/`Response`/`AbortController`, `history.pushState`/`replaceState`/`back`/`forward`/`go`/`popstate` & `URL`/`URLSearchParams` live SPA routing, `crypto.getRandomValues`/`randomUUID`/`subtle.digest`, `performance.mark`/`measure`, and 2D `<canvas>` transforms/bezier curves/gradients/`getImageData`/`putImageData`.
- **Networking and TLS**: Speaks HTTP/1.1 and HTTP/2 (over ALPN `h2` on Windows Schannel and Linux OpenSSL) with origin-keyed connection pooling, RFC 9113/9218 HTTP/2 stream prioritization (`StreamPriority`, `exchange_multiplexed_prioritized`, `discover_html_subresources`, `fetch_batch_prioritized`), RFC 7541 HPACK header compression, DEFLATE/zlib/gzip decompression, HAR 1.2 network trace export, cookies, HSTS, CSP, and Subresource Integrity (`sha256-` and `sha3-256-`). On Linux, OpenSSL offers the `X25519MLKEM768` post-quantum hybrid group first and shows the negotiated group on `anvil://security`. Includes an in-house TLS 1.3 implementation (ML-KEM-768, X25519, `X25519MLKEM768`, SHA-3/SHAKE, AES-128/256-GCM, and HKDF-SHA256); page loads still connect through OpenSSL or Schannel after the TLS 1.3 self-test passes.
- **Process isolation, Brave Shields, and privacy**: Runs each tab in its own `--renderer` process (with optional Linux `bwrap`/`unshare`/`prlimit` confinement, Windows job limits and low-integrity labels, and a checked painted-frame draw mode on `anvil://security`). Links Brave Browser's unmodified `adblock-rust` crate (`adblock::Engine`, MPL-2.0) for ABP/uBlock Origin network filter matching, `@@` exceptions, `$important`, `$redirect` script/frame surrogates, `$removeparam` tracking query parameter stripping, cosmetic element hiding (`##` and `#@#`), and per-site Shields Up/Down controls on `anvil://shields` (`anvil://security`). Supports HTTPS-only mode, top-level site cookie partitioning, and per-site script and cookie permissions.
- **Native desktop UI, responsive 1080p/1440p/4K scaling, tabs, and tools**: Renders the browser shell chrome through a native C++20 Direct2D + DirectWrite + Win32/DWM UI shell with ClearType proportional typography (`Segoe UI`, `Segoe UI Semibold`, `Cascadia Mono`), monitor-aware default window sizing and high-DPI zoom for 1080p (`1920x1080`), 1440p (`2560x1440`), and 4K (`3840x2160`) displays, an integrated 38px top tab strip with `4x4` SSAA anti-aliased Anvil emblem, adaptive tab widths, draggable titlebar region, and Windows 11 Minimize/Maximize/Close caption buttons, a pill-shaped Omnibox with domain-highlighted URL, inline Security pill, inline Shields pill, and floating suggestion popover, a floating bottom-left link-hover/loading status pill, zero-copy and dirty-row (`D3D11_BOX`) Direct3D 11 SwapChain presentation, and responsive 2-column left sidebar navigation + multi-column card layouts across `anvil://home`, `anvil://settings`, `anvil://security`, `anvil://downloads`, `anvil://history`, and `anvil://inspector`. Supports pinned tabs, tab reordering (`Ctrl+Shift+PageUp`/`PageDown`), closed-tab restore (`Ctrl+Shift+T`), duplicate/close-other-tabs, four themes (`Dark`, `Midnight`, `Light`, `Nordic`), mouse-drag page text selection, full caret and word-level text editing, a 5-tab `F12` DevTools dock (`Elements`, `Styles` with live inline CSS override editing, `Network` waterfall log, `Console` REPL, and `Storage` inspector), `view-source:` (`Ctrl+U`), `Ctrl+S` page saving, automatic file downloads (`anvil://downloads`), find in page (`Ctrl+F`), and page zoom (`75%`–`150%`).
- **Media, maps, and search**: Decodes PNG, JPEG, GIF, WebP (`VP8L` and `VP8 `), BMP, ICO, and TrueType/OpenType fonts (`glyf`, `CFF `, `kern`, `GPOS`). Plays `AVID`/`ADCT`, RFC 6386 `VP8`, clean-room `VP9` (uncompressed header + 8x8 DCT/IDCT intra/inter frames + superframe index), and `AV1` (`AOMedia OBU` sequence/frame headers + 8x8 DCT/IDCT intra/inter + CDEF filter) MP4/WebM clips and RFC 6716 `Opus` (SILK/CELT) / `PCM` / `ADPCM` / `FLAC` / `MDCT` audio with `AudioOutputBridge` master audio clock A/V drift tracking and streaming PCM16 ringbuffer. While the media pipeline implements specification-guided RFC 6386 VP8, VP9, AV1 OBU, and RFC 6716 Opus codecs, it does not implement every third-party entropy/transform mode, and H.264 containers still wrap `ADCT` payloads. Includes a built-in tile map (`anvil://maps`) and clean result formatting for Google, DuckDuckGo, and Bing search pages.
