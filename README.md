Anvil is a small desktop browser built in Rust, C++20 (native Direct2D + DirectWrite + Win32/DWM desktop UI shell in `ui/` and SIMD/VM helpers in `engines/`), JavaScript/TypeScript (`frontend/` and self-hosted **Cinder** JS VM & JIT in `engines/cinder`), and CSS (**Prism** CSS engine in `engines/prism/stylesheets/` and `frontend/styles/`), powered by the **Anvil Forge Engine** (`anvil-engine`) and integrating Brave Browser's open-source `adblock-rust` crate (`../adblock-rust`, MPL-2.0) for network and cosmetic ad/tracker blocking. It runs on Linux and Windows.

It's a proof of concept, so expect rough edges. Current version: 0.24.4 (`v.24.4`).

See [CHANGELOG.md](./CHANGELOG.md) for what changed in each release.

## Try it

Windows 64-bit builds (`AnvilBrowser-Setup-v.24.4-win64.exe` and a portable `anvil.exe`) are on the [releases page](https://github.com/buntatoes/anvil-browser/releases), or build it from source below.

## Build it

You need Rust 1.99.1 or newer. On Linux you also need the X11 and OpenSSL development files (`sudo apt install libx11-dev libssl-dev` on Debian or Ubuntu). A C++20 compiler builds the native Direct2D/DirectWrite desktop UI engine (`ui/`) on Windows and the C++20 CSS/JS engine helpers (`engines/prism/cpp` and `engines/cinder/cpp`).

Clone this repo, [anvil-engine](https://github.com/buntatoes/anvil-engine), [adblock-rust](https://github.com/brave/adblock-rust), and the nine companion libraries below side by side in one folder, then run this from `anvil-browser`:

```sh
cargo test -- --test-threads=1
cargo run --release -p anvil-browser --bin anvil
```

## What it does

- **HTML, CSS, and layout**: Parses HTML with WHATWG HTML5 error recovery (active formatting element reconstruction across misnested inline tags, table foster parenting, implicit heading/paragraph/list/table auto-closure, and foreign `<svg>`/`<math>` self-closing tags), inline `<svg>` icons and shapes, tables (`colspan`, `rowspan`, and intrinsic column sizing), `<details>`/`<summary>` accordions, `<dialog>` modal/non-modal elements, and form controls (`<input>`, `<textarea>`, `<select>`, checkboxes, radios, range sliders, `<progress>`, and `<meter>`). Applies the CSS cascade (the in-tree `engines/prism` engine and native C++20 CSS kernels linked directly into `anvil-style`: Selectors Level 4 with `:scope`, `@font-face`, `font-family` (`Sans`, `Serif`, `Mono`), `text-transform` (`uppercase`, `lowercase`, `capitalize`), `letter-spacing`, `word-spacing`, `text-decoration: underline | line-through`, `::before` and `::after` generated content pseudo-elements with `content: "..." | attr(...)`, interactive/validation states `:hover`/`:active`/`:focus`/`:focus-visible`/`:focus-within`/`:target`/`:valid`/`:invalid`/`:in-range`/`:out-of-range`, CSS Nesting (`&`), `@media`, `@supports` with selector/declaration fault recovery, `@layer` cascade layers with `!important` layer inversion and `revert-layer`, `@scope (<root>) to (<limit>)` scoped cascade boundaries with ancestor hop proximity, `@property` custom property registration, CSS-wide keywords `initial`/`inherit`/`unset`/`revert`/`revert-layer` and `all`, `@container` size queries, `@starting-style`, CSS Color 4/5 `color(display-p3 | xyz-d50 | xyz-d65)`, `color-mix()`, `light-dark()`, `linear-gradient()`, `radial-gradient()`, `conic-gradient()`, `repeating-linear-gradient()`, and `repeating-radial-gradient()`, `backdrop-filter: blur(...)` and `filter` (`blur`, `brightness`, `contrast`, `grayscale`, `invert`, `sepia`, `saturate`), per-side border colors, `outline`/`outline-offset`, `object-fit` (`fill`, `contain`, `cover`, `none`, `scale-down`), scrollable overflow containers (`overflow: auto | scroll` with mouse-wheel routing and 6px overlay scrollbars), W3C stacking context order (`z-index < 0`, normal flow, `z-index: 0`, `z-index > 0`), CSS Values 4 math `calc()`/`min()`/`max()`/`clamp()`/`round()`/`mod()`/`rem()`/trig/exponential and universal viewport/font units across box edges, `text-overflow: ellipsis`, `overflow-wrap: break-word` / `word-break: break-all`, CSS Logical Properties, standalone `translate`/`scale`/`rotate`, custom properties with recursive `var(--missing, fallback)` recovery, `box-sizing`, `aspect-ratio`, complete Flexbox and CSS Grid, transitions, and keyframe animations) and draws through the CPU and `anvil-gpu` batched scene passes (`GpuSceneBatch`) with gamma-correct linear-space glyph blending, multi-family bold/italic glyph synthesis (`anvil-ttf` 0.10.0), 4-bin (`0.25 px`) subpixel phase positioning, and pairwise kerning and bounded glyph and image caches.
- **JavaScript and WebAssembly**: Runs page scripts and WebAssembly 1.0 modules under a step and memory budget with per-`<script>` and statement-level fault isolation (`window.onerror`, `ErrorEvent`, `PromiseRejectionEvent`, `unhandledrejection`). `anvil-script` links the in-tree `engines/cinder` engine directly (a register bytecode VM with mark-sweep GC, hidden classes, 4-way polymorphic inline caches, ES2022–ES2024 classes/`#private` fields/destructuring/regex/`async`-`await`, Generators `function*`/`yield`/`yield*`, Async Generators `async function*` / `for await...of` / `[Symbol.asyncIterator]`, `BigInt`, ES module `import`/`export`/`import.meta`/`import()` lowering, `Proxy` and `Reflect`, `WeakMap`/`WeakSet`/`WeakRef`/`FinalizationRegistry`, `DataView`/`ArrayBuffer`/`TypedArray`s, `Symbol.for`/`Symbol.keyFor`, `Error(..., { cause })`, `AggregateError`, `Intl`, and live `CinderDomHost` W3C 3-phase DOM event propagation `Capture -> Target -> Bubble` with `once`/`capture`/`passive`/`signal`/`stopImmediatePropagation`/`composedPath`, live layout/scroll DOM geometry `getBoundingClientRect()` / `getComputedStyle(el, pseudoElt)` / `offsetWidth` / `offsetHeight` / `clientWidth` / `clientHeight` / `scrollWidth` / `scrollHeight` / `scrollTop` / `scrollLeft` / `scrollTo` / `scrollBy`, HTML5 `<dialog>` `show()`/`showModal()`/`close()`, HTML5 Form Constraint Validation `validity`/`checkValidity()`/`reportValidity()`/`setCustomValidity()`, `File`/`FileList`/`FileReader`/`DataTransfer`/`navigator.clipboard`, live scroll/resize `IntersectionObserver` & `ResizeObserver` re-evaluation, `Element`/`ChildNode`/`ParentNode` mutation methods, `TreeWalker`/`NodeIterator`/`Range`/`Selection`, `fetch`/`Headers`/`Request`/`Response`/`AbortController`, `history.pushState`/`replaceState`/`popstate`, `crypto.getRandomValues`/`randomUUID`/`subtle.digest`, `performance.mark`/`measure`, and 2D `<canvas>` transforms/bezier curves/gradients/`getImageData`/`putImageData` via `eval_with_cinder_engine`, alongside the self-hosted ES2022–ES2024 compiler and DOM runtime on the C++20 `CinderVM`).
- **Networking and TLS**: Speaks HTTP/1.1 and HTTP/2 (over ALPN `h2` on Windows Schannel and Linux OpenSSL) with origin-keyed connection pooling, cookies, HSTS, CSP, and Subresource Integrity (`sha256-` and `sha3-256-`). On Linux, OpenSSL offers the `X25519MLKEM768` post-quantum hybrid group first and shows the negotiated group on `anvil://security`. `anvil-net` also includes an in-house TLS 1.3 implementation built on `anvil-pqc` and `anvil-cipher`; page loads still connect through OpenSSL or Schannel after the TLS 1.3 self-test passes.
- **Process isolation, Brave Shields, and privacy**: Runs each tab in its own `--renderer` process (with optional Linux `bwrap`/`unshare`/`prlimit` confinement, Windows job limits and low-integrity labels, and a checked painted-frame draw mode on `anvil://security`). Links Brave Browser's unmodified `adblock-rust` crate (`adblock::Engine`, MPL-2.0) for ABP/uBlock Origin network filter matching, `@@` exceptions, `$important`, `$redirect` script/frame surrogates, `$removeparam` tracking query parameter stripping, cosmetic element hiding (`##` and `#@#`), and per-site Shields Up/Down controls on `anvil://shields` (`anvil://security`). Supports HTTPS-only mode, top-level site cookie partitioning, and per-site script and cookie permissions.
- **Native C++20 desktop UI, responsive 1080p/1440p/4K scaling, tabs, and tools**: Renders the browser shell chrome through a native C++20 Direct2D + DirectWrite + Win32/DWM UI engine (`ui/anvil_core_abi.h`, `ui/anvil_ui_d2d.cpp`, `ui/anvil_ui_window.cpp`) with ClearType proportional typography (`Segoe UI`, `Segoe UI Semibold`, `Cascadia Mono`), monitor-aware default window sizing and high-DPI zoom for 1080p (`1920x1080`), 1440p (`2560x1440`), and 4K (`3840x2160`) displays, an integrated 38px top tab strip with `4x4` SSAA anti-aliased Anvil emblem (`anvil-image` 0.8.0 mipmap downsampling), adaptive tab widths, draggable titlebar region, and Windows 11 Minimize/Maximize/Close caption buttons, a pill-shaped Omnibox with domain-highlighted URL (`split_url_for_domain_highlight`), inline Security pill, inline Shields pill, and floating suggestion popover, a floating bottom-left link-hover/loading status pill, zero-copy and dirty-row (`D3D11_BOX`) Direct3D 11 SwapChain presentation (`present.rs`), and responsive 2-column left sidebar navigation + multi-column card layouts across `anvil://home`, `anvil://settings`, `anvil://security`, `anvil://downloads`, `anvil://history`, and `anvil://inspector`. Supports pinned tabs, tab reordering (`Ctrl+Shift+PageUp`/`PageDown`), closed-tab restore (`Ctrl+Shift+T`), duplicate/close-other-tabs, four themes (`Dark`, `Midnight`, `Light`, `Nordic`), mouse-drag page text selection, full caret and word-level text editing, a 5-tab `F12` DevTools dock (`Elements`, `Styles` with live inline CSS override editing, `Network` waterfall log, `Console` REPL, and `Storage` inspector), `view-source:` (`Ctrl+U`), `Ctrl+S` page saving, automatic file downloads (`anvil://downloads`), find in page (`Ctrl+F`), and page zoom (`75%`–`150%`).
- **Media, maps, and search**: Decodes PNG, JPEG, GIF, WebP (`VP8L` and `VP8 `), BMP, ICO, and TrueType/OpenType fonts (`glyf`, `CFF `, `kern`, `GPOS`). Plays `AVID`/`ADCT` MP4/WebM clips with `anvil-video` 0.9.0 (`v.09`). That version also adds VP8, VP9, and AV1 style frame headers and an Opus packet header and range decoder, but the frames inside are still `anvil-video`'s own `ADCT` format, so real VP8, VP9, AV1, and Opus streams from the web don't play yet. Includes a built-in tile map (`anvil://maps`) and clean result formatting for Google, DuckDuckGo, and Bing search pages.

## How it's laid out

This repo houses the browser shell (`crates/`), the native C++20 Direct2D/DirectWrite desktop UI engine (`ui/`), the TypeScript/TSX built-in pages (`frontend/`), and the in-tree **Prism** CSS engine (`engines/prism`) and **Cinder** JS VM & JIT (`engines/cinder`) that link directly into the Rust core (`anvil-style` and `anvil-script`). The **Anvil Forge Engine** lives in [anvil-engine](https://github.com/buntatoes/anvil-engine), Shields adblocking links Brave Browser's unmodified [adblock-rust](https://github.com/brave/adblock-rust) crate (`MPL-2.0`), and the browser builds with all nine standalone companion libraries:

- [anvil-cipher](https://github.com/buntatoes/anvil-cipher), [anvil-compress](https://github.com/buntatoes/anvil-compress), [anvil-hpack](https://github.com/buntatoes/anvil-hpack), [anvil-image](https://github.com/buntatoes/anvil-image), [anvil-json](https://github.com/buntatoes/anvil-json), [anvil-pqc](https://github.com/buntatoes/anvil-pqc), [anvil-ttf](https://github.com/buntatoes/anvil-ttf), [anvil-gpu](https://github.com/buntatoes/anvil-gpu), [anvil-video](https://github.com/buntatoes/anvil-video)
