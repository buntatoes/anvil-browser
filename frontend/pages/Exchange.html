Move to another Anvil

Writes your bookmarks, the addresses of your open tabs, and a few settings (theme, search engine, zoom, HTTPS-only) to a plain JSON file you name, so another Anvil can read them. The file is not encrypted, so anyone who can open it can read it.

History goes in only if you tick it. Cookies, site storage, downloads, and saved logins never go in. Nothing is written or read unless you press a button here, and nothing is sent over the network.
