Your own scripts

Put .js files in the userscripts folder next to profile.anvil. Each file needs at least one line like // @match https://example.com/* near the top to say where it runs. New files start off.

A script that is on runs after the page's own scripts, on the http and https pages it matches. It gets the page and fetch(), with the same rules and limits as the page's own scripts, and nothing more. It never runs on anvil:// pages, and it doesn't run where JavaScript is off ({{scriptsGlobal}} on the settings page, or blocked for the site). Files that ask for @grant anything but none don't run.
